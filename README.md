# LX Portfolio – Lidetu Tesfaye

## Overview
LX Portfolio is a modern, responsive personal portfolio website for Lidetu Tesfaye, a Software Developer and AI Automation Creator. This site showcases professional skills, projects, services, and contact information in a visually engaging and interactive way.

## Features
- **Collapsible Sidebar:** Modern sidebar navigation that can be collapsed/expanded for a clean user experience.
- **Hero Section:** Eye-catching introduction with a tech-themed background and a summary of expertise.
- **About Me:** Brief biography, background, and contact details.
- **Stats:** Animated counters for clients, projects, and more.
- **Skills:** Visual representation of technical skills and tools.
- **Resume:** Education and professional experience timeline.
- **Portfolio/Projects:** Highlighted projects with descriptions and direct GitHub links.
- **Services:** List of professional services offered.
- **Contact:** Contact form and real map location (Adama, Ethiopia – ASTU).
- **Responsive Design:** Looks great on desktop and mobile devices.
- **Modern UI:** custom CSS, and smooth animations.

## Technologies Used
- HTML5, CSS3 (custom)
- JavaScript (with AOS, Typed.js, PureCounter, and more)
- OpenStreetMap for location

## How to Use
1. **Clone or Download:**
	- Download the repository or clone it using `git clone `.
2. **Open in Browser:**
	- Open `index.html` in your web browser.
3. **Customize:**
	- Update content in `index.html` and assets as needed for your own use.
